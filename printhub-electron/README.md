# PrintHub Desktop — Setup Guide

> Manual print operator console for shop owners.  
> **Zero automatic printing.** You click Print. You are in control.

---

## What changed from the old version

| Old (broken) | New (fixed) |
|---|---|
| Passwords stored in plaintext in `electron-store` | Supabase session **tokens** stored — never the password |
| Supabase credentials hardcoded in `main.js` | Credentials loaded from `.env` file — never committed |
| Double login on startup (race condition) | Single session restore via token refresh |
| No config validation — silent crash | Config errors shown with clear instructions |
| `electron-builder` incompatible with Node 24 | Upgraded to latest `electron-builder` |
| Missing `assets/` folder — build fails | Icons auto-generated by `npm run generate:icons` |
| README described auto-print + SumatraPDF | README updated to match actual manual workflow |
| No `.gitignore` | `.gitignore` prevents committing `.env` or `dist/` |

## Quick start (development)

```powershell
# 1. Go into the Electron app folder
cd printhub-electron

# 2. Install dependencies
npm install

# 3. Copy the example config and fill in your credentials
copy .env.example .env
# Then open .env and set SUPABASE_URL and SUPABASE_ANON_KEY

# 4. Generate app icons
npm run generate:icons

# 5. Run in dev mode (opens DevTools automatically)
npm run dev
```

---

## Environment configuration

Create a file called `.env` in the `printhub-electron/` directory:

```env
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_ANON_KEY=eyJhbGci...
```

Get these values from: **Supabase Dashboard → Settings → API**

> ⚠️ Use the **anon / public** key only. Never use the `service_role` key in the desktop client.

The `.env` file is listed in `.gitignore` and will never be committed.

## Building the Windows installer

```powershell
# Generates the NSIS installer at dist/Printhub Setup 1.0.0.exe
npm run build:win
```

The installer:
- Installs to `C:\Users\<name>\AppData\Local\Programs\Printhub` by default
- Creates a Start Menu shortcut
- Offers a Desktop shortcut option
- Offers to launch PrintHub after installation
- Provides an uninstall entry in Windows Settings → Apps

> **Note:** The installer does **not** bundle a `.env` file. After installation, the shopkeeper must provide their Supabase credentials via the login screen (credentials are stored securely as session tokens after first login).

## Database setup (Supabase)

The application uses an existing Supabase database. Apply the migration below if your database was created from scratch:

```sql
-- migrations/001_initial_schema.sql
-- Run this in Supabase SQL Editor

-- Profiles (extends auth.users)
CREATE TABLE IF NOT EXISTS profiles (
  id        uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  name      text,
  email     text,
  phone     text,
  role      text NOT NULL DEFAULT 'customer' CHECK (role IN ('customer','owner','admin')),
  created_at timestamptz NOT NULL DEFAULT now()
);

-- Auto-create profile on signup
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS trigger LANGUAGE plpgsql SECURITY DEFINER AS $$
BEGIN
  INSERT INTO profiles (id, email, name, role)
  VALUES (new.id, new.email, COALESCE(new.raw_user_meta_data->>'name', ''), 'customer')
  ON CONFLICT (id) DO NOTHING;
  RETURN new;
END;
$$;

DROP TRIGGER IF EXISTS on_auth_user_created ON auth.users;
CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();

-- Shops
CREATE TABLE IF NOT EXISTS shops (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  owner_id   uuid REFERENCES profiles(id) ON DELETE SET NULL,
  name       text NOT NULL,
  address    text,
  shop_code  text UNIQUE,
  status     text NOT NULL DEFAULT 'open' CHECK (status IN ('open','busy','paused','offline')),
  created_at timestamptz NOT NULL DEFAULT now()
);

-- Orders
CREATE TABLE IF NOT EXISTS orders (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  shop_id         uuid NOT NULL REFERENCES shops(id) ON DELETE CASCADE,
  user_id         uuid REFERENCES profiles(id) ON DELETE SET NULL,
  token           text,
  file_name       text,
  file_url        text,
  pages           int  NOT NULL DEFAULT 1,
  copies          int  NOT NULL DEFAULT 1,
  color_mode      text NOT NULL DEFAULT 'bw' CHECK (color_mode IN ('bw','colour')),
  paper_size      text NOT NULL DEFAULT 'A4',
  sides           text NOT NULL DEFAULT 'single' CHECK (sides IN ('single','double')),
  orientation     text NOT NULL DEFAULT 'portrait',
  notes           text,
  is_priority     boolean NOT NULL DEFAULT false,
  priority_fee    int  NOT NULL DEFAULT 0,
  payment_mode    text NOT NULL DEFAULT 'online' CHECK (payment_mode IN ('online','offline')),
  payment_status  text NOT NULL DEFAULT 'unpaid' CHECK (payment_status IN ('unpaid','paid')),
  razorpay_id     text,
  status          text NOT NULL DEFAULT 'pending',
  amount_total    int  NOT NULL DEFAULT 0,
  amount_shop     int  NOT NULL DEFAULT 0,
  amount_platform int  NOT NULL DEFAULT 0,
  created_at      timestamptz NOT NULL DEFAULT now(),
  updated_at      timestamptz NOT NULL DEFAULT now()
);

-- Auto-update updated_at
CREATE OR REPLACE FUNCTION update_updated_at()
RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN NEW.updated_at = now(); RETURN NEW; END; $$;

DROP TRIGGER IF EXISTS orders_updated_at ON orders;
CREATE TRIGGER orders_updated_at
  BEFORE UPDATE ON orders
  FOR EACH ROW EXECUTE FUNCTION update_updated_at();

-- Print job log
CREATE TABLE IF NOT EXISTS print_jobs (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id    uuid REFERENCES orders(id) ON DELETE CASCADE,
  printer     text,
  job_status  text NOT NULL DEFAULT 'pending',
  error_log   text,
  printed_at  timestamptz,
  created_at  timestamptz NOT NULL DEFAULT now()
);

-- ── Row Level Security ──────────────────────────────────────────────────────
ALTER TABLE profiles  ENABLE ROW LEVEL SECURITY;
ALTER TABLE shops     ENABLE ROW LEVEL SECURITY;
ALTER TABLE orders    ENABLE ROW LEVEL SECURITY;
ALTER TABLE print_jobs ENABLE ROW LEVEL SECURITY;

-- Profiles: users can read their own; admins can read all
CREATE POLICY "profiles_own"        ON profiles FOR SELECT USING (auth.uid() = id);
CREATE POLICY "profiles_admin_all"  ON profiles FOR ALL    USING (EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'admin'));
CREATE POLICY "profiles_self_update" ON profiles FOR UPDATE USING (auth.uid() = id);

-- Shops: anyone can read non-offline shops (for customer shop listing)
CREATE POLICY "shops_public_read"   ON shops FOR SELECT USING (status != 'offline');
CREATE POLICY "shops_owner_update"  ON shops FOR UPDATE USING (owner_id = auth.uid());
CREATE POLICY "shops_admin_all"     ON shops FOR ALL    USING (EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'admin'));

-- Orders: customers can create; shop owners see own shop; admins see all
CREATE POLICY "orders_insert_any"   ON orders FOR INSERT WITH CHECK (true);
CREATE POLICY "orders_customer_own" ON orders FOR SELECT USING (user_id = auth.uid() OR user_id IS NULL);
CREATE POLICY "orders_shop_owner"   ON orders FOR ALL    USING (shop_id IN (SELECT id FROM shops WHERE owner_id = auth.uid()));
CREATE POLICY "orders_admin_all"    ON orders FOR ALL    USING (EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'admin'));

-- Print jobs: shop owners see their shop's jobs; admins see all
CREATE POLICY "printjobs_shop_owner" ON print_jobs FOR ALL USING (
  order_id IN (SELECT o.id FROM orders o JOIN shops s ON o.shop_id = s.id WHERE s.owner_id = auth.uid())
);
CREATE POLICY "printjobs_admin_all"  ON print_jobs FOR ALL USING (
  EXISTS (SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'admin')
);
```

## First-launch flow

1. Install `Printhub Setup 1.0.0.exe`
2. Launch PrintHub from Start Menu or Desktop
3. Enter your shop owner email and password
4. PrintHub authenticates with Supabase and loads your shop
5. Go to **Settings** → **Default Printer** → select your printer
6. New orders appear automatically when customers place them on the website

## Workflow

```
Customer uploads PDF on website
         ↓
Order created in Supabase
         ↓
PrintHub receives realtime notification
         ↓
Order card appears in dashboard
         ↓
Shopkeeper reviews: copies, paper, color, duplex
         ↓
Clicks PRINT
         ↓
PrintHub downloads PDF → verifies printer → prints via Electron native API
         ↓
Order marked as "completed" in Supabase
         ↓
Customer's tracking page shows "Ready to collect"
```

## Troubleshooting

| Problem | Solution |
|---|---|
| "Configuration Error" on startup | Create `.env` file with your Supabase credentials |
| "No printer selected" | Go to Settings → select a default printer |
| "Printer offline" | Check USB/network connection; use Windows Settings → Printers |
| "Session expired — please log in again" | Your session token expired; log in again (only needed once per ~60 days) |
| "Realtime: Offline" dot | Check internet; free Supabase projects pause after inactivity |
| Build fails with `exports is not defined` | Upgrade electron-builder: `npm install electron-builder@latest --save-dev` |

## Manual configuration requirements

The following items require manual setup and cannot be automated:

1. **Supabase credentials** — Get from Supabase Dashboard → Settings → API and put in `.env`
2. **Supabase SQL migration** — Run `migrations/001_initial_schema.sql` in Supabase SQL Editor (only needed for new databases)
3. **Razorpay key** — Update `RAZORPAY_KEY` in `printhub-user/env.js` or Vercel env vars
4. **Vercel environment variables** — Set `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `RAZORPAY_KEY` in Vercel project settings
5. **Admin account** — After first user signup, run: `UPDATE profiles SET role = 'admin' WHERE email = 'your@email.com';` in Supabase SQL Editor
6. **Shop registration** — Use admin panel at `/admin.html` to register shops and assign owners
